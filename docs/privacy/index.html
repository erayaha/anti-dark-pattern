Privacy Policy

Commitment to Privacy & Zero Data Collection

At Erayaha, we build tools that protect users. We adhere to a strict zero-telemetry, privacy-by-default architecture across all our open-source software and hosted static web pages.

Local Execution & No Code Transmission

When you execute `anti-dark` in your local terminal or continuous integration environment, all parsing and heuristic compliance checks are performed 100% locally on your machine. Your source code, file paths, repository structure, and analysis findings are never transmitted to external servers, cloud providers, or third-party analytics platforms.

Static Website Data Practices

This documentation site is hosted on GitHub Pages as static HTML, CSS, and JavaScript. We do not use tracking cookies, browser fingerprinting, advertising networks, or third-party tracking pixels. Server logs maintained by GitHub are governed by GitHub's Privacy Statement.

Open Source Licensing

Anti-Dark Pattern is released under the MIT Open Source License. You are free to inspect, audit, modify, and self-host the source code at any time.

Contacting Us Regarding Privacy

If you have questions about our data practices or software architecture, please contact contact@erayaha.org.
